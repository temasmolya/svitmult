Набір для GitHub Pages — «Світ мультфільмів»

Що робити:
1. Створи новий репозиторій на GitHub.
2. Завантаж у нього ВСІ файли з цієї папки.
3. Переконайся, що index.html лежить у корені репозиторію.
4. На GitHub відкрий: Settings → Pages.
5. У Build and deployment вибери:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
6. Натисни Save.
7. Зачекай кілька хвилин — GitHub Pages згенерує посилання на сайт.

Що всередині:
- index.html — готовий сайт
- .nojekyll — щоб GitHub Pages не обробляв сайт через Jekyll
- README_GitHub_Pages.txt — ця інструкція

Важливо:
- Якщо мінятимеш текст або кнопки, редагуй файл index.html.
- Якщо захочеш додати власне посилання на форму / дошку / вправи, заміни потрібні href у коді.
